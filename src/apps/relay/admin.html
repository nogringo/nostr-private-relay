Backup

Downloads a compacted copy of the database: every stored event, with the access lists, blocked IPs and relay info. Anyone who gets the file sees all of it, so keep it as safe as the server. To restore it, stop the relay and put the file in place of data.mdb in its db directory.

Erase a pubkey's data

Deletes every event the pubkey signed and every gift wrap addressed to it. It can still store new events unless you ban it.

Who can use this relay

While the allow list is empty, any pubkey can sign in and store events. Add one pubkey and only allowed pubkeys and admins can. Banned pubkeys can't sign in or store anything, and a ban takes effect on open connections too.
